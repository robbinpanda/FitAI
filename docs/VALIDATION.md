# 本次验证记录

日期：2026-09-29。环境：Windows 本机，Python + Node.js；生产 HTTP 依赖 Waitress 3.0.2。

## 已通过

- 原业务 Python 回归 80 项；账号与安全 Python 测试 15 项，共 95 项。
- 前端 Node.js 测试 37 项（原 34 项 + 3 项安全回归）。
- 实际 Waitress TCP 请求：注册、Secure Cookie、登录后读取状态、Nginx 约定的真实 IP 头传递。
- WSGI 流式队列：生产者结束之前能收到 SSE 数据；主页并行读取不会误触发账号繁忙。
- 访问控制：未登录不能读取状态、导出、照片、聊天图片、后台任务；A/B 账号数据、Key、照片、会话、任务隔离。
- 邀请码缺失/错误/过期、剩余次数耗尽、账号总数限制、持久化限流、注销/过期会话和切换后旧 CSRF 均有覆盖。
- SSRF：不可信来源、HTTP、私网/回环/阿里云元数据 DNS 地址被拒绝；禁用重定向。
- XSS：导入的工具名称、状态和会话 ID 经转义，不能拼出注入 HTML。
- 浏览器手动流程：测试账号登录 → 概要与模型配置加载 → 模拟 AI 流式回复 → 待确认记录 → 应用内退出切换弹窗 → 返回登录页。
- Python / JavaScript 语法检查、Git whitespace 检查。

所有测试使用临时数据和模拟模型，没有读取或改写正式账号记录，也没有调用付费模型 API。
